# МукаПро 0.2 — Android MVP

Рабочий Android-проект на Kotlin + Jetpack Compose + Yandex MapKit.

## Что уже есть

- экран МукаПро 0.2;
- поиск адреса через Yandex MapKit;
- реальная карта после подключения API-ключа;
- демо-слой парковок;
- фильтры: все / бесплатные / дворы / платные;
- Parking Score;
- построение автомобильного маршрута через MapKit Full;
- кнопка «Я припарковался»;
- переход к приложению «Парковки России» при наличии пакета;
- демонстрация защиты от GPS-скачков;
- запрос разрешений геолокации.

## Запуск

1. Откройте папку `mukapro-android` в Android Studio.
2. Получите API-ключ MapKit в кабинете разработчика Яндекс.
3. Создайте `local.properties` в корне проекта и добавьте:

```properties
MAPKIT_API_KEY=ваш_ключ
```

4. Выполните Gradle Sync.
5. Запустите `app` на Android API 26+.

MapKit SDK 4.42.0 используется в соответствии с актуальной документацией Яндекса.

## Важное ограничение 0.2

Парковки сейчас являются демонстрационным набором данных. Реальная база PostgreSQL/PostGIS, сервер Parking Engine, реальные московские парковочные зоны и пользовательские наблюдения — следующий слой разработки. Архитектура Android уже подготовлена так, чтобы заменить демо-данные API без переписывания UI.

NaviKit в проект пока не включён: его использование требует отдельного подключения/активации у Яндекса. На 0.2 автомобильная маршрутизация выполняется через Full MapKit.
